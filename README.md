# PM – Capstone Project (Aurelia AI Datacenter Conversion Program)

- `Capstone/GUIDE.md` – guide to the files, key results, MS Project steps, warnings (English).
- `Capstone/GUIDA_ITALIANO.md` – same guide in Italian.
- `Capstone/deliverables/` – the 5 deliverables (Charter, Master Plan XML, Risk Plan, Risk Register, Financial Model).
- `Capstone/model/` – Python model that generates the deliverables (`engine.py` scheduler/cash flow, `optimize.py`
  NPV search, `export_msp.py` MS Project XML, `build_fin_xlsx.py` Excel, `build_docs.py` Word, `risks.py` risk register,
  `solution.json` selected decisions, `Datacenter_Data_Updated.xlsx` instructor data).
