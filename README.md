# PM – Capstone Project (Aurelia AI Datacenter Conversion Program)

- `Capstone/GUIDA_ITALIANO.md` – guida ai file, risultati, passi da fare in MS Project, avvertenze.
- `Capstone/deliverables/` – i 5 deliverable (Charter, Master Plan XML, Risk Plan, Risk Register, Financial Model).
- `Capstone/model/` – modello Python che genera i deliverable (`engine.py` scheduler/cash-flow, `optimize.py`
  ricerca NPV, `export_msp.py` XML MS Project, `build_fin_xlsx.py` Excel, `build_docs.py` Word, `risks.py` registro rischi,
  `solution.json` decisioni selezionate, `Datacenter_Data_Updated.xlsx` dati del docente).
